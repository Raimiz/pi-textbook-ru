# История русской редакции

Здесь фиксируются содержательные изменения русской версии Pi Textbook.

Файл не дублирует историю Git. В него попадают изменения, важные для читателя и редакционного процесса: переведённые разделы, пересмотр терминов, крупная редактура, новые примечания и выпуски.

Формат основан на принципах Keep a Changelog, но адаптирован для редакционного проекта.

### Добавлено

- Русская локализация главной страницы и основных элементов навигации.

- Редакционная политика перевода.

### Утверждено

- `Session Tree` → «дерево сессий».
- `Streaming` → «потоковая обработка» как базовый термин.
- `Context Compression` → «сжатие контекста».
- `Trace` → «трассировка».
- `Layer` → «слой».
- Названия `Pi`, `Tool Calling`, `Agent Loop`, `runtime`, `checkpoint` и `prompt` сохраняются без перевода.
- Интерфейсные формы: «Курс», «Методика», «Глоссарий».
- Кнопки: «Начать курс», «Продолжить обучение», «Следующая глава», «Вернуться к checkpoint».
