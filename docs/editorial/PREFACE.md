# Предисловие к русскому изданию

> Статус: рабочие материалы. Финальный текст будет написан после завершения перевода и сквозного редакторского прохода.

## Зачем существует этот файл

Предисловие не должно быть рекламой Pi или пересказом содержания. Его задача — дать русскоязычному читателю контекст:

- что представляет собой Pi Textbook;
- почему книга важна именно как инженерный курс;
- кому она будет полезна;
- чем её метод отличается от материалов, начинающихся с готового фреймворка;
- как устроена русская редакция;
- где заканчивается авторский текст и начинаются примечания редакторов.

## Предварительная структура

### 1. Почему появился русский перевод

Русскоязычное сообщество пока мало знакомо с Pi, а качественных материалов, которые последовательно показывают внутреннее устройство LLM-агента, немного.

### 2. Это книга не только о Pi

Pi выступает референсной реализацией. Основной предмет книги — инженерные причины появления потоковой обработки, Tool Calling, Agent Loop, дерева сессий, сжатия контекста и runtime.

### 3. Метод курса

Система строится постепенно. Новая абстракция появляется только после того, как читатель увидел ограничение предыдущей реализации. Каждая глава оставляет воспроизводимый checkpoint и проверяет важные свойства тестами.

### 4. Кому будет полезна книга

Предварительно:

- разработчикам, которые хотят понимать устройство agent harness;
- пользователям готовых coding agents, которым не хватает архитектурной картины;
- инженерам, проектирующим собственный runtime, память, инструменты или оркестрацию;
- читателям, которые хотят отличать реальные механизмы от маркетинговой терминологии.

### 5. Принципы русской редакции

Переводить смысл, а не синтаксис. Сохранять инженерную точность. Не улучшать автора молча. Редкие пояснения явно отмечать как примечания переводчика.

### 6. Благодарности

Поблагодарить автора оригинала и участников, которые помогали проверять терминологию, код и русский текст.

## Материалы для будущего текста

Сюда по мере работы переносятся только краткие тезисы из [`OBSERVATIONS.md`](./OBSERVATIONS.md), которые прошли проверку по всей книге.

Перед выпуском v1.0 необходимо:

- перечитать весь курс;
- подтвердить центральные наблюдения конкретными главами;
- убрать предварительные сравнения, которые книга не поддерживает;
- написать связный текст объёмом ориентировочно 1–2 страницы;
- явно обозначить, что предисловие относится к русскому изданию.
